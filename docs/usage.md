# Usage

1. Request and unzip a Grok/X data export.
2. Select the folder containing `prod-grok-backend.json` and
   `prod-mc-asset-server`.
3. Use the dashboard for aggregate activity and the explorer for transcripts.
4. Use branch controls to select a regeneration path.
5. Use **Retry Remote Images** for remote URLs that may still be available.
6. Export the open conversation as a plain-text transcript.

The app processes data locally. Browser storage can be cleared from the app or
through browser site-data controls.
