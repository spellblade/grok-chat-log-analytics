# Security Policy

## Supported versions

Only the latest version on the default development branch is actively
maintained.

## Reporting a vulnerability

Do not disclose security issues in a public issue or pull request. Report them
privately to the project maintainer through the repository's private security
advisory channel, including:

- a clear description of the issue;
- reproduction steps or a minimal proof of concept;
- affected version and browser/runtime;
- the potential impact.

This application is local-first, but imported exports and remote image URLs
must still be treated as untrusted input.
